# Need for synchroniszation

A program is a series of operations which will be executed on a computer. The timeline of events happening in the program is consistent with the order of the operations in the code.

But when optimizations are enabled the final generated machine code might look very different from the code. The compiler is allowed to perform any combination of optimizations, as long as the final optimized code, when executed, produces the same results as the one without optimizations.

Due to the [[15. concurrency|concurrency]] involved in modern computers, assumptions about the program’s execution order are often wrong.
