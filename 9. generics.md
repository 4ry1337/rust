# Generics

Rust declares generics via generic parameters, and implements (compiles) them via [[monomorphization]].

# Generic Parameters

[[functions|Functions]], type aliases, structs, enumerations, unions, [[2. traits|traits]], and [[implementations]] may be parameterized by types, constants, and lifetimes.

These parameters are listed in angle brackets (<...>), usually immediately after the name of the item and before its definition. For implementations, which don’t have a name, they come directly after impl.

The order of generic parameters is restricted to lifetime parameters and then type and const parameters intermixed.

^generic-decl-order

The same parameter name may not be declared more than once in a GenericParams list.

^duplicate-params

> [!EXAMPLE]
> ```rust
> fn foo<'a, T>() {}
> trait A<U> {}
> struct Ref<'a, T> where T: 'a { r: &'a T }
> struct InnerArray<T, const N: usize>([T; N]);
> struct EitherOrderWorks<const N: bool, U>(U);
> ```

`'_` and `'static` are not valid lifetime parameter names.

^invalid-lifetimes

## Const generics

Const generic parameters allow items to be generic over constant values.

> [!EXAMPLE] where const generic parameters can be used.
> ```rust
> // Used in the signature of the item itself.
> fn foo<const N: usize>(arr: [i32; N]) {
>     // Used as a type within a function body.
>     let x: [i32; N];
>     // Used as an expression.
>     println!("{}", N * 2);
> }
> 
> // Used as a field of a struct.
> struct Foo<const N: usize>([i32; N]);
> 
> impl<const N: usize> Foo<N> {
>     // Used as an associated constant.
>     const CONST: usize = N * 4;
> }
> 
> trait Trait {
>     type Output;
> }
> 
> impl<const N: usize> Trait for Foo<N> {
>     // Used as an associated type.
>     type Output = [i32; N];
> }
> ```

> [!EXAMPLE] where const generic parameters cannot be used
> ```rust
> fn foo<const N: usize>() {
>     // Cannot use in item definitions within a function body.
>     const BAD_CONST: [usize; N] = [1; N];
>     static BAD_STATIC: [usize; N] = [1; N];
>     fn inner(bad_arg: [usize; N]) {
>         let bad_value = N * 2;
>     }
>     type BadAlias = [usize; N];
>     struct BadStruct([usize; N]);
> }
> ```
