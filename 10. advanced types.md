# Trait Object

A *trait object* is an opaque value of another type that implements a set of traits.

The set of traits is made up of a [[10. advanced types#Dyn-compatible trait|dyn compatible]] base trait plus any number of [[auto traits]].

Trait objects implement the base trait, its auto traits, and any [[2. traits#Supertraits|supertraits]] of the base trait.

There must be at least one trait bound, there may not be more than one non-auto trait, no more than one lifetime, and opt-out bounds (e.g., ?Sized) and [[9. generics#Use bounds|use<..> bounds]] are not allowed.

> [!EXAMPLE] given a trait Trait, the following are all trait objects:
> ```rust
> dyn Trait
> dyn Trait + Send
> dyn Trait + Send + Sync
> dyn Trait + 'static
> dyn Trait + Send + 'static
> dyn Trait +
> dyn 'static + Trait.
> dyn (Trait)
> ```

## Dyn-compatible trait

Dispatch is the mechanism to determine which specific version of code is actually run when it involves [[polymorphism]].

Two major forms of dispatch are static dispatch and dynamic dispatch. Rust supports dynamic dispatch through the use of trait objects.
