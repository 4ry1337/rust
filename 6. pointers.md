# Pointer Types

All pointers are explicit first-class values. They can be moved or copied, stored into data structs, and returned from functions.

## References

### Shared Reference (&)

Shared references point to memory which is owned by some other value. As the name suggests, any number of shared references to a value may exist.

When a shared reference to a value is created, it prevents direct mutation of the value. [[Interior mutability]] provides an exception for this in certain circumstances.

Copying a reference is a “shallow” operation: *pointers are Copy*.

### Mutable references (&mut)

Mutable references point to memory which is owned by some other value.

A mutable reference (that hasn’t been borrowed) is the only way to access the value it points to, so is not Copy.
