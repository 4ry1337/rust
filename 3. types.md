Rust types:

- Primitive types:
    - Boolean — `bool`
    - Numeric — integer and float
    - char
    - str
    - Never — `!` — a type with no values
- Sequence types:
    - Tuple
    - Array
    - Slice
- User-defined types:
    - Struct
    - Enum
    - Union
- Function types:
    - Functions
    - Closures
- Pointer types:
    - References
    - Raw pointers
    - Function pointers
- Trait types:
    - Trait objects
    - Impl trait
