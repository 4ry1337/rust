## Rust types
Rust types:

- Primitive types:
    - Boolean — `bool`
    - Numeric — integer and float
    - char
    - str
    - Never — `!` — a type with no values
- Sequence types:
    - Tuple
    - Array
    - Slice
- User-defined types:
    - Struct
    - Enum
    - Union
- Function types:
    - Functions
    - Closures
- Pointer types:
    - References
    - Raw pointers
    - Function pointers
- Trait types:
    - Trait objects
    - Impl trait

### Inferred types

The inferred type asks the compiler to infer the type if possible based on the surrounding information available.

### Recursive types

*Nominal types* may be recursive. That is, type field may refer, directly or indirectly, to the enclosing type itself.

Restrictions:
- types must include a nominal type in the recursion (not mere type aliases, or other structural types such as arrays or tuples).
- The size of a recursive type must be finite (Sized)

### Dynamically Sized Types (DST)

Most types have a fixed size that is known at compile time and implement the trait `Sized`.

^Sized

A type with a size that is known only at run-time is called *a dynamically sized type (DST)* or, informally, *an unsized type*.

> [!NOTE]
> [[2. variables|Variables]], function parameters, [[2. variables#const|const]] items, and [[2. variables#static|static]] items must be `Sized`.

[[Pointer types]] to DSTs are sized but have twice the size of pointers to sized types, since they also store metadata:
- Pointers to [[slices]] store the number of elements; pointers to [[str]] store the length in bytes.
- Pointers to [[trait objects]] store a pointer to a [[vtable]].
- Pointers to a struct or tuple with an [[unsized tail]] store the same metadata as a pointer to that tail.

### Casting

Rust has no [[Literature Notes/programming languages/type/conversion#Coercion|coercion]] between primitive types. But, [[Literature Notes/programming languages/type/conversion#Casting|casting]] can be performed using the `as` keyword.
